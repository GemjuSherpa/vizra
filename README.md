# AI Agentic Video Generator

This application uses a multi-agent pipeline to:
1. Search for query results using Google Search API (Mocked).
2. Get a response from an LLM.
3. Combine the search results and LLM response.
4. Generate a short video (3-5 seconds).

## How to run
Please ensure you have the required dependencies installed.
(Note: For a production environment, replace the mock parts with actual API keys.)
